# Drop your PNGs here

| file | where it shows up |
|------|-------------------|
| `icon.png` | the cartridge slot on the title screen (replaces the `?`) |
| `1.png` … `6.png` | the six vault tiles, in order |

Nothing else to change — each slot picks its file up as soon as it exists.

**Before the file is there:** the cartridge keeps its `?`, and a vault tile
opens onto a dashed box naming the file it is waiting for. Drop the PNG in and
tap that tile again; it loads straight away.

**Shapes:** the cartridge icon looks best square. Vault tiles are square and
crop to fill, but the full-size viewer always shows the whole picture, so
anything works.
